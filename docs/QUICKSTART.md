# Hermes Android 上手指南

Hermes Android 是连接到你自己的 Hermes Gateway 的客户端。项目不提供 Gateway、托管服务、账号或访问凭据。开始前，请准备一个手机可访问、你有权使用的 Gateway，以及它要求的登录方式。

## 1. 安装

从 [GitHub Releases](https://github.com/wsztdd-ui/hermes-android/releases/latest) 下载 `Hermes-Android-v1.0.3-signed.apk`，在 Android 手机上安装并打开。最低支持 Android 8.0（API 26）。

如果 Android 提示不允许安装此来源的应用，请按系统提示临时允许你使用的浏览器或文件管理器安装 APK。安装完成后，可关闭该来源的安装权限。

## 2. 添加并登录 Gateway

1. 打开底部的 **更多** 页面。
2. 在 **连接与服务器** 下点 **网关连接管理**，再点 **添加新连接…**。
3. 输入 Gateway 的 HTTPS 地址，例如 `https://hermes.example.com`，然后继续。
4. 等待连通性检查完成，并按 Gateway 配置完成登录。OAuth 会打开登录流程；其他认证方式按应用提示操作。
5. 登录后应用会重新载入并连接到该 Gateway。

连接地址必须使用 HTTPS。Gateway 需要能从手机网络访问；如果只在家中局域网可用，请先确保手机与服务器网络互通。添加前可以用浏览器确认该地址能够打开。

## 3. 开始聊天

1. 打开 **会话** 页面，选择已有会话，或点 **+** 创建新会话。
2. 在底部输入框输入内容并发送。当前会话及其附件会发送给你配置的 Gateway。
3. 如需为当前会话切换模型，点输入区上方的模型名称，先选提供商，再选模型。模型列表来自 Gateway 当前可用配置。
4. 要修改全局默认模型，进入 **更多 → 默认模型设置**，同样按“提供商 → 模型”选择。

## 4. 多 Bot 群聊

多 Bot 群聊需要你的 Hermes Gateway 实现 `groups.*` 群聊接口；较旧版本会在页面中提示升级 Gateway。

1. 打开 **更多 → 多 Bot 群聊 → 新建多 Bot 群聊**。
2. 输入群聊名称，并从当前 Gateway 的 Agent 配置中选择 2–6 个成员。
3. 发送问题开始协作。可以在消息里用 `@profile` 点名；不点名时，群内 Bot 会自行判断是否需要回应。
4. 点 **群聊设置** 可停止当前协作、重命名或解散房间。

## 5. 管理多个连接

在 **更多 → 网关连接管理** 中可以添加其他连接，也可以点已有连接切换主连接。切换后应用会重新载入。若当前 Gateway 的登录状态失效，可选择 **重新登录当前网关…**。

## 遇到问题

- **地址不可达：** 检查是否为 HTTPS、域名和端口是否正确，以及 Gateway 是否允许手机所在网络访问。
- **登录未完成：** 返回连接管理，选择重新登录；需要 OAuth 时，在登录页完成授权后回到应用。
- **没有模型或模型不可用：** 请 Gateway 管理员检查服务端提供商和模型配置；本客户端不会创建模型账号或 API 密钥。
- **连接或隐私疑问：** 阅读[隐私说明](../PRIVACY.md)。连接令牌由 Android Keystore 保护；请只连接可信 Gateway。
